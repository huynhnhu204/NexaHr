# NexaHR Features

## Roles

ADMIN — full access | HR — HR modules | MANAGER — team scope | EMPLOYEE — self-service

## Modules

Nhân sự, chấm công, nghỉ phép, lương, tuyển dụng (+ careers portal), đào tạo, tài sản, KPI, báo cáo, AI Copilot, workflow, Data Hub, billing, SSO, mobile.

## Multi-tenant

Mọi dữ liệu scoped theo `companyId` trong JWT. Đổi công ty qua Company Switcher.
